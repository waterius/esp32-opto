## Уровни достоверности

В документах каждое утверждение помечено, откуда оно:

- **[проверено]** — подтверждено даташитом или документацией (ссылка рядом или в [sources.md](sources.md));
- **[по схеме]** — выведено из разбора эталонной схемы;
- **[по фото]** — выведено по фото платы (941×938 px), перед пайкой прозвонить;
- **[гипотеза]** — не проверено;
- **[измерить]** — проверяется мультиметром на месте.

## Коротко

1. SoftwareSerial не нужен: у ESP32-C6 два аппаратных UART + LP UART, пины назначаются через GPIO Matrix.
2. К USB D+/D− головки подключиться нельзя: USB у C6 — только устройство (Serial/JTAG), хоста нет.
3. Доработка головки: 1 разрез дорожки TXD + 4 провода (5V, GND, TX, RX).
