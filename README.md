# esp32-opto

Чтение электросчётчиков через оптопорт IEC 62056-21 (IEC 61107) на
**ESP32-C6 Super Mini** с доработанной китайской оптоголовкой
(RIXUTECH «кабель-адаптер CP2102», внутри — CP2102N).

Идея: не городить свою ИК-часть, а взять готовую головку с магнитом и
оптикой, отключить от неё USB-мост и завести её UART прямо в ESP32.

Документация — в [docs/](docs/README.md).
